# Third-party sources

- Desktop base: [dsh-tauri/deepseek-harness-desktop](https://github.com/dsh-tauri/deepseek-harness-desktop). Original LICENSE and LICENSE.details are retained in the parent project and source archive.
- Design packages: [nexu-io/open-design](https://github.com/nexu-io/open-design/tree/17e255959703a3fad7c8eb7f7b70dcafccc5629a/design-systems), Apache-2.0, pinned to commit `17e255959703a3fad7c8eb7f7b70dcafccc5629a`. Apple, Duolingo and Atelier Zero rules, tokens and component references are retained with the upstream license at `server/designs/LICENSE`. The existing 晴空、纸间、薄荷 palettes are original.
- Current preview capture: [html-to-image](https://github.com/bubkoo/html-to-image), MIT, pinned to 1.11.13. Its library runs locally inside the isolated preview iframe.
- Candidate rendering: [Playwright](https://github.com/microsoft/playwright), Apache-2.0, pinned to 1.63.0. Chromium is installed separately; candidate rendering blocks external network requests and creates a separate context for each screenshot.
- Speech inference: [k2-fsa/sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx), [Apache-2.0 license](https://github.com/k2-fsa/sherpa-onnx/blob/master/LICENSE). npm package sherpa-onnx-node 1.13.8.
- Speech model: Alibaba Group / FunAudioLLM **SenseVoiceSmall**, int8 ONNX conversion distributed by k2-fsa. Resource name: `sherpa-onnx-sense-voice-zh-en-ja-ko-yue-int8-2024-07-17`. [Official download](https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-int8-2024-07-17.tar.bz2). [SenseVoice project](https://github.com/FunAudioLLM/SenseVoice), [FunASR model license](https://github.com/modelscope/FunASR/blob/main/MODEL_LICENSE). Preserve the model name, source and author information when redistributing weights. Weights are installed locally by `asr:setup` and excluded from the source ZIP.
- WeChat delivery integration: official `miniprogram-ci` 2.1.31 from npm. Its native compiler could not load in the current standalone Node environment; no official WeChat runtime result is claimed.
- WXML/WXSS compilation: WeChat MiniProgram team's [glass-easel](https://github.com/wechat-miniprogram/glass-easel), [MIT license](https://github.com/wechat-miniprogram/glass-easel/blob/master/LICENSE). npm packages `glass-easel-template-compiler` and `glass-easel-stylesheet-compiler`, both pinned to 1.2.1. These are official compiler components; running them is separate from Developer Tools preview, upload and physical-device verification.
- Conversation rendering: [react-markdown](https://github.com/remarkjs/react-markdown), [MIT license](https://github.com/remarkjs/react-markdown/blob/main/license), pinned to 10.1.0. Replies use its CommonMark renderer without raw HTML execution or remote image elements.
- Speech text extraction: [mdast-util-from-markdown](https://github.com/syntax-tree/mdast-util-from-markdown), [MIT license](https://github.com/syntax-tree/mdast-util-from-markdown/blob/main/license), pinned to 2.1.0. Formatting is parsed with the same CommonMark syntax used by the reply renderer; original conversation records are preserved.

Third-party dependencies remain subject to their own licenses. This file records provenance and does not replace the original licenses.
